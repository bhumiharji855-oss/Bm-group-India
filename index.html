Google Sheet Setup

Ek baar karna hai, 5 minute. Iske baad har order apne aap Sheet me aayega.

1
Computer par sheets.google.com kholein aur ek blank sheet banayein (naam: BM Group Orders).
2
Sheet ke menu se Extensions → Apps Script kholein.
3
Wahan jo purana code likha hai use poora delete karein, aur neeche wala code paste karein.
4
Save dabayein (Ctrl + S).
5
Deploy → New deployment → gear icon → Web app chunein.
6
“Execute as” me Me, “Who has access” me Anyone chunein → Deploy → Authorize access → apna Google account → Allow.
7
Jo Web app URL mile (script.google.com/macros/s/... se shuru), use copy karein.
8
App me Owner Panel → Google Sheet Auto-Sync me URL paste karke Save dabayein.
9
Test Order dabayein — Sheet me ek test line aa jayegi. Bas, ho gaya!
